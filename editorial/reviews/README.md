# Monday Editorial Review archive

Sent Monday emails are saved here as `YYYY-MM-DD.md` (same body as the email).

Each review includes the closing ask: **Do not resurface — is there anything I should stop bringing up?** Owner replies land in `captures/owner/`; Sunday Claude adds/expires them in `status.md`.

Sunday Claude also reads the newest file’s **Follow through this week** target to mark `continued:` / `resolved:` / `blocked:` (or `closed:` / `killed:` if that target is on a suppression list).

See repo root `README.md` for the full workflow.
