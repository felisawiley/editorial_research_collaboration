# Claude captures inbox

Drop Claude editorial deltas here as `YYYY-MM-DD.md`.

The Monday Editorial Weekly agent reads **new/unprocessed** files in this folder and applies them to `editorial/status.md`.

How files get here:
1. Claude Cowork scheduled task outputs the delta → you save/download into this folder and push, **or**
2. Claude Code routine with GitHub access writes the file into this path on `main`, **or**
3. You paste a manual Claude summary into a new dated file here

Processed filenames are listed in `editorial/status.md` under `Processed Claude captures`.
